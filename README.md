# 📊 Deaz & Co Executive Business Dashboard

Interactive Retail Sales Analytics Dashboard built using Python, Streamlit, and Plotly.

## Dashboard Preview

(gambar dashboard)

## Business Problem

Retail companies need to monitor sales performance, profitability, and customer purchasing trends to support business decisions.

## Objectives

- Analyze sales performance
- Identify profitable categories
- Understand regional performance
- Provide business recommendations

## Dataset

- Period: 2011–2014
- Records: 8,047
- Country: Indonesia

## Tools

- Python
- Pandas
- Streamlit
- Plotly
- Jupyter Notebook
